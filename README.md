# Fydinn — Where Real Connections Begin

Fydinn is a modern dating application designed for intentional connections. We prioritize shared values, identity verification, and meaningful interactions over endless swiping.

---

## Features

- **Smart Matching Algorithm** — Our intelligent matching system prioritizes shared values and lifestyle habits over superficial traits, helping you find compatible partners.

- **Verified Profiles** — Every member undergoes mandatory identity verification to ensure a safe and trustworthy community.

- **Secure Messaging** — Encrypted chat and built-in safety tools protect your privacy throughout your entire journey on Fydinn.

- **Event Curation** — Receive local date suggestions based on mutual interests, making first meetings natural and memorable.

- **Value-Based Connection** — We focus on intentional conversations that matter, helping you move beyond small talk to meaningful dialogue.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn package manager
- Modern web browser

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd fydinn-web
```

2. Install dependencies:

```bash
cd fyd-idea
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The optimized build will be generated in the `dist/` directory.
